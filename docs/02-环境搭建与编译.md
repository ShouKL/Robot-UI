## 3. 环境搭建与编译

### 3.1 系统要求

| 需求 | 版本/说明 |
|------|-----------|
| **操作系统** | Windows 10/11 x64 |
| **编译器** | Visual Studio 2022 或 2026 |
| **GPU** | 支持 Vulkan 1.3+ 的显卡 |
| **内存** | ≥8 GB |

### 3.2 依赖安装

#### 3.2.1 必需依赖

| 依赖 | 下载链接 | 系统环境变量 |
|------|----------|-------------|
| **OpenCV 4.12.0** | https://opencv.org/releases/ | `OPENCV` → `...\opencv\build` |
| **GStreamer MSVC x86_64** | https://gstreamer.freedesktop.org/download/ | `GSTREAMER` → `...\gstreamer\1.0\msvc_x86_64` |
| **Vulkan SDK 1.4.341.1** | https://vulkan.lunarg.com/sdk/home | `VULKAN_SDK` → `...\VulkanSDK\1.4.341.1` |
| **MuJoCo 3.8.0** | https://github.com/google-deepmind/mujoco/releases | `MUJOCO` → `...\mujoco` |

#### 3.2.2 环境变量配置

打开系统环境变量设置，添加以下变量：

```
变量名          值
OPENCV          C:\opencv\build
GSTREAMER       C:\gstreamer\1.0\msvc_x86_64
VULKAN_SDK      C:\VulkanSDK\1.4.341.1
MUJOCO          C:\mujoco
```

并在 `PATH` 中添加：

```
%OPENCV%\x64\vc16\bin
%GSTREAMER%\bin
%MUJOCO%\bin
```

### 3.3 克隆与编译

```powershell
# 1. 克隆仓库（含子模块）
git clone --recursive https://github.com/ShouKL/Robot-UI.git
cd Robot-UI

# 2. 生成 VS2026 解决方案
.\scripts\Setup.bat

# 或者生成 VS2022 解决方案（编辑 scripts\Setup.bat，将 vs2026 改为 vs2022）

# 3. 用 Visual Studio 打开 Robot-UI.slnx，选择配置 (Debug/Release/Dist) 编译
```

### 3.4 构建配置

项目使用 **Premake5** 构建系统，支持三种配置：

| 配置 | 说明 |
|------|------|
| **Debug** | 调试符号、无优化、OpenCV Debug 库 |
| **Release** | 优化编译、带调试符号、OpenCV Release 库 |
| **Dist** | 发布版本 (与 Release 类似) |

编译器选项：
- C++ 标准: **C++20**
- 字符集: **UTF-8** (`/utf-8`)
- 预处理器: `/EHsc /Zc:preprocessor /Zc:__cplusplus`
- 宏定义: `WL_PLATFORM_WINDOWS`, `YAML_CPP_STATIC_DEFINE`, `WL_DEBUG`(Debug)
