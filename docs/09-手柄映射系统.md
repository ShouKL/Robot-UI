## 10. 手柄映射系统

### 10.1 GamepadMapper — 手柄映射器

**文件**: `Robot-UI/src/GamepadMapper.h`, `GamepadMapper.cpp`

#### 数据结构

```cpp
enum class GamepadType { Xbox, Custom };

struct GamepadKey {
    int id;
    std::string name;
    bool is_analog;     // 模拟量 (摇杆) vs 数字量 (按键)
};

struct KeyMapping {
    int key_id;
    std::string key_name;       // 逻辑名称
    std::string gamepad_key;    // 物理按键绑定
    ImVec2 key_pos;             // 可视化位置
    bool is_bound;
    bool is_analog;
};
```

#### 按键信息

```cpp
struct KeyInfo {
    ImVec2 pos;           // 按键圆心
    ImVec2 textPos;       // 文字位置
    float radius;         // 按键半径
    std::string name;     // 显示名称
    std::string label;    // GLFW 标识
    int glfw_id;          // GLFW 按键/轴 ID
    bool is_axis;         // 是否为轴（摇杆）
    bool axis_positive;   // 轴正方向
};
```

### 10.2 手柄映射流程

```
1. 创建 GamepadMapper 配置
   ├→ 选择类型: Xbox 或 Custom
   ├→ 添加逻辑按键 (AddKey)
   └→ 绑定物理按键 (GLFW ID)

2. 手柄线程 (GamepadRoutine)
   ├→ 100Hz 轮询 glfwGetJoystickAxes/Buttons
   ├→ 构建 keyValues map (逻辑名 → 浮点值)
   └→ RobotStatus::EvaluateIntoActuator(keyValues, actuatorConfig)

3. 节点图求值
   ├→ InputNode 获取 keyValues
   ├→ 拓扑排序求值
   └→ OutputNode 写入 ActuatorConfig

4. 发送指令
   └→ HardwareInterface::SendActuatorData(actuatorConfig)
```

### 10.3 Xbox 手柄映射

支持标准 Xbox 控制器的所有按键和轴：

```
GLFW 轴 ID:
  0: 左摇杆 X     1: 左摇杆 Y
  2: 右摇杆 X     3: 右摇杆 Y
  4: LT (左扳机)  5: RT (右扳机)

GLFW 按键 ID:
  0: A        1: B        2: X        3: Y
  4: LB       5: RB       6: Back     7: Start
  8: 左摇杆按下  9: 右摇杆按下
  10: DPad Up  11: DPad Right  12: DPad Down  13: DPad Left
```
