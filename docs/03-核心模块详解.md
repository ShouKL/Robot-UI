## 4. 核心模块详解

### 4.1 Robot_UI_Layer — 主入口层

**文件**: `Robot-UI/src/Robot_UI.h`, `Robot_UI.cpp`

这是应用程序的主层，继承自 `Walnut::Layer`，是整个系统的枢纽：

```cpp
class Robot_UI_Layer : public Walnut::Layer
{
    // ---- 子系统（unique_ptr 持有）----
    std::unique_ptr<OptionPanel>       m_OptionPanel;
    std::unique_ptr<RobotSettingPanel> m_RobotSettingPanel;
    std::unique_ptr<RobotStatus>       m_RobotStatus;
    std::unique_ptr<MonitorWall>       m_MonitorWall;
    std::unique_ptr<ThrustCurveEditor> m_ThrustCurveEditor;
    std::unique_ptr<FileManager>       m_FileManager;
    std::unique_ptr<TerminalPanel>     m_TerminalPanel;

    // ---- 手柄控制线程 ----
    std::thread m_GamepadThread;
    std::atomic<bool> m_Running;
    std::atomic<std::shared_ptr<const ActuatorConfig>> m_CurrentCommand;
};
```

**生命周期**:
1. **构造**: 创建所有子系统、建立依赖注入关系、启动手柄线程、加载配置文件
2. **OnUIRender**: 每帧渲染菜单栏 + 所有打开的窗口
3. **析构**: 保存 .kernel、停止手柄线程、销毁 ImPlot 上下文

**依赖注入关系**（在构造函数中建立）:
```
MonitorWall → LiveStreamManager
NodeGraphManager → RobotComponentManager, GamepadMapperManager, RobotCommManager
RobotStatus → RobotComponentManager (活跃模式), GamepadMapperManager (活跃手柄)
RobotCommManager → RobotComponentManager
```

### 4.2 OptionPanel — 选项面板

**文件**: `Robot-UI/src/OptionPanel.h`, `OptionPanel.cpp`

提供 ImGui 主题切换、样式调整等功能。继承 `EditDraftBase` 支持快照式编辑。

**功能**:
- 9 种 ImGui 主题切换 (WalnutDefault, Cinder, Adobe Spectrum, Enemy Mouse, Led Synthmaster, Dougblinks, Classic, Dark, Light)
- 主题颜色取反 (Invert)
- Alpha 透明度调节
- "Open Robot Setting" 快捷按钮

```cpp
enum class ImGuiTheme {
    WalnutDefault, Cinder, AdobeSpectrum, EnemyMouse,
    LedSynthmaster, Dougblinks, Classic, Dark, Light
};

class ImGuiStyleManager {
    // 每种主题通过独立函数定义：
    ImGuiStyleManager& WalnutDefaultTheme();
    ImGuiStyleManager& CinderTheme();
    // ...
};
```

### 4.3 RobotSettingPanel — 机器人设置面板

**文件**: `Robot-UI/src/RobotSettingPanel.h`, `RobotSettingPanel.cpp`

这是配置管理的核心面板，包含 **5 个标签页**：

```
┌──────────────────────────────────────────────────┐
│ [Component] [Gamepad] [NodeGraph] [LiveStream] [Comm] │
├──────────────────────────────────────────────────┤
│                                                  │
│         对应子管理器的内容区域                      │
│                                                  │
└──────────────────────────────────────────────────┘
```

| 标签页 | 对应管理器 | 功能 |
|--------|-----------|------|
| **Component** | `RobotComponentManager` | 管理机器人模式（电机、舵机、传感器配置） |
| **Gamepad** | `GamepadMapperManager` | 管理手柄映射配置 |
| **NodeGraph** | `NodeGraphManager` | 节点图编辑器（可视化编程） |
| **LiveStream** | `LiveStreamManager` | RTSP 视频流设备管理 |
| **Comm** | `RobotCommManager` | 通信协议配置编辑 |

**快照机制**: 继承 `EditDraftBase`，编辑时：
1. `BeginEdit()` → 拍快照 + 禁用外部同步
2. `ApplyEdit()` → 提交修改 + 恢复同步
3. `CancelEdit()` → 恢复快照 + 恢复同步

### 4.4 RobotStatus — 运行时状态监控

**文件**: `Robot-UI/src/RobotStatus.h`, `RobotStatus.cpp`

负责机器人的**连接管理、数据收发和节点图求值**：

```cpp
class RobotStatus {
    const RobotMode*     m_ActiveMode;       // 指向当前活跃模式（不持有拷贝）
    GamepadMapper*       m_ActiveGamepad;    // 指向当前活跃手柄
    std::unique_ptr<NodeGraph> m_GraphEvaluator;  // 节点图求值器

    bool Link(const RobotCommConfig& cfg);   // 建立连接
    void Unlink();                            // 断开连接
    void SendActuatorData(const ActuatorConfig& data);
    SensorData GetSensorData();
    void EvaluateIntoActuator(const std::map<std::string, float>& keyValues, ActuatorConfig& data);
};
```

**连接流程**:
1. 用户点击 Connect → `RobotStatus::Link(cfg)`
2. 创建 `HardwareInterface` 实例
3. 初始化 UDP/TCP socket
4. 联动 `MonitorWall` → `ConnectStream()`
5. 启动收发循环（手柄线程推送指令）

### 4.5 MonitorWall — 监控墙

**文件**: `Robot-UI/src/MonitorWall.h`, `MonitorWall.cpp`

实时显示 IP 摄像头 RTSP 视频流。与 `RobotStatus` 连接状态联动：

```cpp
class MonitorWall {
    void ConnectStream();     // 自动打开当前选中流
    void DisconnectStream();  // 断开所有流
    void Draw(bool* p_open);  // ImGui 渲染（多选一方式显示）
};
```

### 4.6 TerminalPanel — 终端与日志

**文件**: `Robot-UI/src/TerminalPanel.h`, `TerminalPanel.cpp`

融合 **ImTerm 命令行终端** + **spdlog 日志输出** 的单一面板：

```cpp
class TerminalPanel {
    std::unique_ptr<ImTerm::terminal<TerminalCommands>> m_Terminal;
    void InstallAsLogSink();  // 将面板注册为 spdlog sink
};
```

内置命令：
- `clear` — 清屏
- `help` — 显示帮助
- `quit` — 关闭面板

### 4.7 ThrustCurveEditor — 推力曲线编辑器

**文件**: `Robot-UI/src/ThrustCurveEditor.h`, `ThrustCurveEditor.cpp`

基于 **ImPlot** 的无刷电机推力曲线编辑器：

```
推力曲线模型:
         PWM ↑
    PwmMax |                    ●(pt_end, PwmMax)
           |                  /
           |                ●(pt_mid, pp_mid)
           |              /
           |            ●(0, pp_ini)
           |           /
           |          ●(0, np_ini)
           |         /
           |        ●(nt_mid, np_mid)
           |       /
    PwmMin |______●(nt_end, PwmMin)_______________→ Thrust
           -N              0              +N
```

**功能**:
- 原始数据点表格编辑（添加/删除/修改）
- 自动拟合成 6 个锚点的折线模型
- PWM 区间设置（min/max/default）
- 多电机独立曲线

### 4.8 FileManager — 文件管理器

**文件**: `Robot-UI/src/FileManager.h`, `FileManager.cpp`

纯工具类，职责分离清晰：

```cpp
class FileManager {
    // 路径管理
    std::string m_RobotPath;      // 当前 .rbt 文件路径
    void DeriveKernelPath();      // .rbt → .kernel (同目录同名)

    // 脏状态追踪
    bool m_RobotDirty;
    bool m_KernelDirty;

    // Win32 文件对话框
    static std::string OpenDialog(const char* filter);
    static std::string SaveDialog(const char* filter, const char* defaultExt);

    // 最近文件 (最多10个)
    std::vector<std::string> m_RecentFiles;

    // 路径便携化（绝对↔相对，相对于 exe 目录）
    static std::string ToRelativePath(const std::string& absolutePath);
    static std::string ToAbsolutePath(const std::string& path);
};
```
