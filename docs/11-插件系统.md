## 11.1 概述

Robot-UI 采用 **子进程 + stdin/stdout + JSON-RPC 2.0** 架构，灵感来自 VS Code 的 Language Server Protocol。

```
┌──────────────────────────────────────────────┐
│              Robot-UI 主进程 (C++)             │
│  ┌────────────────────────────────────────┐  │
│  │          PluginManager                 │  │
│  │  ┌──────────┐  ┌──────────┐           │  │
│  │  │ Python 子 │  │ C++ 子进程│  ...     │  │
│  │  │ 进程      │  │           │          │  │
│  │  │ ↕stdin   │  │ ↕stdin    │          │  │
│  │  │ ↕stdout  │  │ ↕stdout   │          │  │
│  │  └──────────┘  └──────────┘           │  │
│  │      JSON-RPC 2.0 管道通信              │  │
│  └────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘
```

| 特性 | 说明 |
|------|------|
| 插件格式 | `.py`（Python）或 `.exe`（C/C++ 编译） |
| 隔离方式 | 独立子进程，崩溃不影响主程序 |
| 通信协议 | JSON-RPC 2.0，每行一个 JSON |
| Python 依赖 | `pip install jsonrpcserver` |

## 11.2 目录结构

```
plugins/
├── robot_ui.py            # Python SDK ← 从这里开始，所有 .py 插件导入它
├── plugin_bridge.py       # Python 桥梁（所有 .py 共用，不需要改）
├── plugin_sdk.h           # C/C++ SDK（header-only）
├── hello.py               # Python 最小示例
├── hello_cpp.exe          # C++ 示例
├── monitor.py             # 状态监控面板（完整参考实现）
└── examples/
    └── hello.cpp          # C++ 源码
```

## 11.3 快速开始 —— Python 插件

### 第一步：生成模板

```powershell
python robot_ui.py --template    # 打印模板代码，复制到 my_plugin.py
python robot_ui.py --help        # 查看全部文档
python robot_ui.py --paths       # 查看变量路径格式
```

### 最小模板

```python
# my_plugin.py — 最小 Python 插件
PLUGIN_NAME = "MyPlugin"
PLUGIN_VERSION = "1.0.0"
PLUGIN_AUTHOR = "your name"

from robot_ui import api          # ← SDK，一行导入

def on_load():
    api.help()                    # 首次加载打印帮助
    print("可用变量:", api.list_paths())
    return True

def on_enable(): return True
def on_disable(): return True
def on_unload(): return True

def on_update(params):
    # 读取数据——用 SDK 方法，无需知道内部路径！
    temp = api.sensor("temperature", params)   # → 25.3 or None
    thr  = api.gamepad("throttle", params)     # → 0.75 or None
    spd  = api.node_out("motor.speed", params) # → 100.0 or None
    print(f"温度={temp}  油门={thr}  速度={spd}")
    return True
```

放入 `plugins/` 目录，在 Plugin Manager 中 Refresh → Enable 即可运行。

### 工作流程

```
python -u plugin_bridge.py my_plugin.py    ← 主程序自动调用
         ↓
plugin_bridge 加载 my_plugin 模块
         ↓
自动调用 api._setup() 连接上 RPC 通道
         ↓
api.xxx() 全部可用
```

## 11.4 SDK 速查 — `from robot_ui import api`

| 方法 | 说明 | 示例 |
|------|------|------|
| `api.list_paths()` | 获取所有可监控路径 | `["sensors/temperature", ...]` |
| `api.subscribe(paths)` | 订阅路径（开始收数据） | `api.subscribe(["sensors/temperature"])` |
| `api.unsubscribe()` | 取消订阅 | `api.unsubscribe()` |
| `api.sensor(name, params)` | 提取传感器值 | `api.sensor("temperature", params)` |
| `api.gamepad(name, params)` | 提取图输入值 | `api.gamepad("throttle", params)` |
| `api.node_var(name, params)` | 提取全局变量 | `api.node_var("my_global", params)` |
| `api.node_out(name, params)` | 提取图输出值 | `api.node_out("motor.speed", params)` |
| `api.dt(params)` | 提取帧间隔(秒) | `api.dt(params)` → `0.016` |
| `api.state(paths)` | 一次性获取状态快照 | `api.state(["sensors/temperature"])` |
| `api.option(key)` | 读取选项 | `api.option("ng_source")` |
| `api.set_option(k, v)` | 设置选项 | `api.set_option("ng_source", "editor")` |
| `api.help()` | 打印帮助 | `api.help("on_update")` 查看 params 结构 |

> 所有方法都有 docstring，可用 `help(api.sensor)` 查看。

### on_update 中的数据

`on_update(params)` 收到一个 dict，包含：

| 键 | 内容 | SDK 方法 |
|----|------|----------|
| `sensors` | `{temperature, humidity, depth}` | `api.sensor(name, params)` |
| `gamepad` | `{key: value, ...}` (图输入 Key 节点) | `api.gamepad(name, params)` |
| `node_graph.variables` | `{name: value, ...}` (全局变量) | `api.node_var(name, params)` |
| `node_graph.outputs` | `{path: value, ...}` (图输出) | `api.node_out(name, params)` |
| `dt` | 帧间隔秒数 | `api.dt(params)` |

## 11.5 订阅模式

默认情况下，未订阅的插件**不会**收到 `on_update`。你需要先看有哪些路径，再订阅需要的：

```python
from robot_ui import api

def on_enable():
    # 看看有哪些变量
    paths = api.list_paths()
    print("可用变量:", paths)

    # 订阅需要的路径（C++ 端只推这些）
    api.subscribe(["sensors/temperature", "gamepad/throttle"])
    return True

def on_disable():
    api.unsubscribe()
    return True
```

## 11.6 创建 GUI — tkinter

插件的 `run_ui()` 函数会在**后台线程**中被调用，适合运行 tkinter 窗口。

```python
def run_ui():
    """主程序会在后台线程调用此函数"""
    import tkinter as tk
    root = tk.Tk()
    root.title("My Panel")
    tk.Label(root, text="Hello!").pack()
    root.mainloop()
```

**注意事项**：
- tkinter 必须在创建它的线程中运行，不要跨线程操作控件
- 在主线程更新 UI 用 `root.after(0, callback)`
- 数据处理和 UI 绘制分开，数据层用 `threading.Lock` 保护

参考 `monitor.py` 中的 `MonitorApp` 类，它是一个完整的 tkinter 数据监控面板实现。

## 11.7 C/C++ 插件

使用 `plugin_sdk.h`（header-only），编译为独立 `.exe`。

```cpp
// hello.cpp
#include "../plugin_sdk.h"

PLUGIN_INFO("HelloCpp", "1.0.0", "dev")

int on_load()    { LOG_INFO("Hello from C++!"); return 0; }
int on_enable()  { return 0; }
int on_disable() { return 0; }
int on_unload()  { return 0; }
int on_update()  { return 0; }

REGISTER_PLUGIN()
```

编译：
```powershell
# MSVC
cl /EHsc /O2 /Fe:hello_cpp.exe hello.cpp

# MinGW
g++ -O2 -o hello_cpp.exe hello.cpp -static
```

放入 `plugins/` 目录即可。

## 11.8 调试插件

### Python 插件

1. 查看 `plugins/_bridge_dbg.txt`（自动生成的调试日志）
2. 在代码中手动写文件：`open("debug.txt", "a").write(f"...\n")`
3. 不要在插件中用 `print()` — stdout 被 JSON-RPC 占用，会干扰通信

### C++ 插件

- 用 Visual Studio 附加到 `hello_cpp.exe` 进程调试
- `plugin_sdk.h` 提供 `LOG_INFO()` / `LOG_ERROR()` 宏

## 11.9 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| Plugin Manager 看不到插件 | `plugin_bridge.py` 不在 `plugins/` 目录 | 确保 `plugin_bridge.py` 存在 |
| Python 插件加载失败 | 未安装 `jsonrpcserver` | `pip install jsonrpcserver` |
| `api.xxx()` 调用都返回 None | SDK 未初始化（不在主程序中运行） | 用 `python robot_ui.py --help` 测试 |
| tkinter 窗口没反应 | 在非主线程操作控件 | 用 `root.after(0, callback)` |
| 取消勾选后仍有数据 | subscribe 未同步 | 确保 subscribe/unsubscribe 调用正确 |
| 日志输出空 `[PLUGIN]` | 管道中有多余输出 | 检查是否有 stray `print()` 或 stderr 输出 |
| 不知道怎么查字段名 | 没有运行 `api.list_paths()` | 在 `on_enable()` 中 print 或运行 `--help` |
