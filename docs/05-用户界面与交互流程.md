### 6.2 菜单结构

```
File
├── Open Robot Config...    (Ctrl+O)    打开 .rbt 文件
├── Save                    (Ctrl+S)    保存当前 .rbt
├── Save As...              (Ctrl+Shift+S)  另存为
├── Save Kernel             (Ctrl+K)    保存 .kernel
├── ─────────────────────
├── Recent Files...                     最近文件列表（最多10个）
├── ─────────────────────
└── Exit                               退出（带未保存提示）

Edit
├── Robot Setting           打开机器人设置面板
├── Option                  打开选项面板
└── Undo / Redo             (计划中)

View
├── Robot Status            显示/隐藏状态面板
├── Monitor Wall            显示/隐藏监控墙
├── Terminal                显示/隐藏终端
└── Node Editor             打开节点图编辑器

Tools
├── Gamepad Debug           手柄调试窗口
└── ─────────────────────

Window
└── (所有可停靠窗口列表)

Help
└── About                   关于对话框
```

### 6.3 典型工作流

#### 工作流 1: 配置新机器人

```
1. File → Open Robot Config
   └→ 加载或创建 .rbt 文件

2. Edit → Robot Setting → Component 标签
   ├→ 创建/编辑机器人模式 (RobotMode)
   ├→ 配置无刷电机 (BrushlessMotor): ID, 名称, 推力曲线
   ├→ 配置舵机 (Servo): ID, 名称
   ├→ 配置运动控制 (MotionControl)
   └→ 配置传感器 (Temperature/Humidity/Depth)

3. Gamepad 标签
   ├→ 创建手柄映射配置
   ├→ 绑定按键到逻辑名称
   └→ 确定手柄类型 (Xbox/Custom)

4. NodeGraph 标签
   ├→ 创建节点图项
   ├→ 拖放节点连接
   ├→ 配置节点参数
   └→ 关联 Gamepad 模式和 Comm 配置

5. Comm 标签
   ├→ 配置目标 IP/端口/传输类型
   ├→ 编辑发送帧协议 (header, fields, checksum, tail)
   └→ 编辑接收帧协议

6. LiveStream 标签
   ├→ 添加摄像头设备
   └→ 配置 RTSP URL / 解码器 / 缓冲参数

7. File → Save (Ctrl+S)
```

#### 工作流 2: 运行与调试

```
1. 确保 Robot Setting 中配置正确
2. Robot Status 面板: 点击 Connect
   ├→ 自动连接实时视频流 (MonitorWall)
   ├→ 开始收发数据
   └→ 状态指示灯变绿

3. 使用游戏手柄操控
   ├→ 手柄线程读取按键值
   ├→ 节点图求值：按键 → 执行器指令
   └→ HardwareInterface 发送二进制帧

4. 实时监控:
   ├→ Robot Status: 传感器数据可视化
   ├→ MonitorWall: 视频流实时画面
   └→ Terminal: 日志输出

5. 调试: Tools → Gamepad Debug 查看手柄原始值
```

#### 工作流 3: MuJoCo 仿真

```
1. asset/Robot/robot.py 运行 Python 仿真
2. 仿真使用 robot.xml 模型定义
3. 模型包含轮腿机器人各部件（仓体、电机、配重等）
4. ROV_API/UnderwaterRobot_Sim 提供 C++ 仿真接口
```
