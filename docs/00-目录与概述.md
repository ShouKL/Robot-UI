## 1. 项目概述

Robot-UI 是一款基于 **Walnut 框架**（Vulkan 渲染）的 Windows 桌面应用程序，专为**水下机器人（ROV）的配置、控制、仿真与监控**而设计。它集成了实时视频流、物理仿真、通信协议编辑、节点图编程和手柄映射等功能。

### 1.1 核心功能

| 功能 | 描述 |
|------|------|
| **机器人模式管理** | 多模式执行器/传感器配置（无刷电机、舵机、运动控制） |
| **节点图编辑器** | 可视化编程，将手柄输入映射为执行器输出 |
| **通信协议编辑器** | 自定义二进制协议帧结构（多帧发送/接收） |
| **RTSP 视频流** | 基于 GStreamer 的实时视频监控墙 |
| **MuJoCo 仿真** | 水下机器人物理仿真 |
| **手柄映射** | Xbox/Custom 手柄按键可视化绑定 |
| **推力曲线编辑器** | 电机推力→PWM 曲线可视化编辑（ImPlot） |
| **终端与日志** | 内置 ImTerm 命令行终端 + spdlog 日志输出 |
| **主题系统** | 9 种 ImGui 主题可切换 |

```
├─────────────────────────────────────────────────┤
│  Video         │ GStreamer (RTSP/H.264/H.265)   │
├─────────────────────────────────────────────────┤
│  Simulation    │ MuJoCo 3.8.0                   │
├─────────────────────────────────────────────────┤
│  Vision        │ OpenCV 4.12.0                  │
├─────────────────────────────────────────────────┤
│  Serialization │ yaml-cpp (YAML)                │
├─────────────────────────────────────────────────┤
│  Logging       │ spdlog                         │
├─────────────────────────────────────────────────┤
│  Network       │ WinSock2 (UDP/TCP)             │
└─────────────────────────────────────────────────┘
```
