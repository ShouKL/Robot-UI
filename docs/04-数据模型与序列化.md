## 5. 数据模型与序列化

### 5.1 Robot API 核心数据结构

**文件**: `Robot-UI/src/Robot_API/robot_api.h`

#### 5.1.1 编码枚举

```cpp
enum class DataEncoding : uint8_t {
    Float32, Float64, Int8, Int16, Int32, Int64,
    Uint8, Uint16, Uint32, Uint64, Bool
};
```

#### 5.1.2 带编码的数值容器

```cpp
struct EncodedValue {
    double value = 0.0;
    DataEncoding encoding = DataEncoding::Float32;
};
```

#### 5.1.3 传感器系统

```cpp
struct TemperatureSensor { EncodedValue value; };
struct HumiditySensor    { EncodedValue value; };
struct DepthSensor       { EncodedValue value; };
struct SensorData {
    TemperatureSensor temperature;
    HumiditySensor    humidity;
    DepthSensor       depth;
    bool is_valid = false;
};
struct SensorConfig {
    bool has_temperature = false;
    bool has_humidity    = false;
    bool has_depth       = false;
};
```

#### 5.1.4 执行器系统

```cpp
struct ThrustCurve {
    // 6 锚点模型
    EncodedValue np_mid, np_ini, pp_ini, pp_mid;
    EncodedValue nt_end, nt_mid, pt_mid, pt_end;
    float pwm_min, pwm_max, default_pwm;
    std::vector<double> raw_thrust;
    std::vector<float>  raw_pwm;
};

struct BrushlessMotor {
    int id;
    std::string name;
    ThrustCurve curve;
    EncodedValue target_speed;
};

struct Servo {
    int id;
    std::string name;
    EncodedValue angle;
};

struct MotionControl {
    EncodedValue x, y, z;     // 位置
    EncodedValue rx, ry, rz;  // 姿态
};

struct ActuatorConfig {
    std::vector<BrushlessMotor> brushlessmotor;
    std::vector<Servo> servo;
    MotionControl motion;
    bool has_motion;
};
```

#### 5.1.5 协议配置

```cpp
struct ProtocolSendConfig {
    char name[32];
    uint8_t command_byte;
    bool enabled;
    std::vector<uint8_t> header;
    std::vector<uint8_t> tail;
    ChecksumType checksum;
    bool include_length;
    bool big_endian;
    std::vector<SendField> fields;
};

struct SendField {
    std::string name;
    std::string field_path;   // e.g., "brushlessmotor.0.target_speed"
    DataEncoding encoding;
    std::string group;
    bool visible;
    bool fix;
    double fix_value;
};
```

### 5.2 ConfigSerializer — YAML 序列化器

**文件**: `Robot-UI/src/ConfigSerializer.h`, `ConfigSerializer.cpp`

使用 **yaml-cpp** 进行所有配置的序列化/反序列化：

```cpp
class ConfigSerializer {
public:
    // .rbt 文件 — 机器人完整配置
    static bool Save(const std::string& filepath, ...);
    static bool Load(const std::string& filepath, ...);

    // .kernel 文件 — UI 状态 + 样式
    static bool SaveKernel(const std::string& filepath, ...);
    static bool LoadKernel(const std::string& filepath, ...);

private:
    // YAML Emit 方法（序列化）
    static void EmitRobotConfig(YAML::Emitter& out, ...);
    static void EmitGamepadMapper(YAML::Emitter& out, ...);
    static void EmitStyle(YAML::Emitter& out, ...);
    static void EmitStreams(YAML::Emitter& out, ...);
    static void EmitUIState(YAML::Emitter& out, ...);
    static void EmitEditorCurve(YAML::Emitter& out, ...);
    static void EmitRobotComm(YAML::Emitter& out, ...);
    static void EmitGraphItems(YAML::Emitter& out, ...);

    // YAML Apply 方法（反序列化）
    static bool ApplyRobotConfig(const YAML::Node& node, ...);
    static bool ApplyGamepadMapper(const YAML::Node& node, ...);
    // ...
};
```

### 5.3 ManagerBase — 管理器基类

**文件**: `Robot-UI/src/ManagerBase.h`

所有管理器共享的抽象接口：

```cpp
class ManagerBase {
public:
    // 纯虚拟：数据访问
    virtual int     GetItemCount() const = 0;
    virtual int     GetItemId(int index) const = 0;
    virtual char*   GetItemNameBuf(int index) = 0;

    // 可选覆写：列表行为
    virtual int  GetSelectedIndex() const;
    virtual bool IsItemSelected(int index) const;
    virtual void SelectItem(int index);
    virtual const char* GetDeleteLabel() const;
    virtual bool CanDeleteItem(int index) const;

    // 统一列表绘制
    virtual void DrawItemList(float width);
    virtual void DrawContent() {}

    // CRUD 操作
    virtual void AddItem() = 0;
    virtual void RemoveItem(int id) = 0;
    virtual void RenameItem(int id, const char* newName) = 0;

    // 窗口控制
    void Open();
    void Close();
    bool IsOpen() const;
};
```
