## 7. 节点图系统

### 7.1 系统架构

节点图系统是 Robot-UI 的核心——将**手柄输入按键值**通过可视化节点网络映射为**执行器输出指令**。

```
┌──────────────────────────────────────────────────────┐
│                   NodeGraphManager                    │
│  ┌─────────────────────────────────────────────────┐ │
│  │  GraphItem[0]  GraphItem[1]  GraphItem[2]  ... │ │
│  └─────────────────────────────────────────────────┘ │
│                       ↓                               │
│  ┌─────────────────────────────────────────────────┐ │
│  │             NodeGraph (Selected)                │ │
│  │  ┌──────┐  ┌──────┐  ┌──────┐                 │ │
│  │  │ Node │──│ Node │──│ Node │  ...            │ │
│  │  └──────┘  └──────┘  └──────┘                 │ │
│  │     ↓ Link     ↓ Link     ↓                     │ │
│  │  EditorLink  EditorLink                         │ │
│  └─────────────────────────────────────────────────┘ │
│                       ↓                               │
│  ┌─────────────────────────────────────────────────┐ │
│  │         NodeGraph Evaluator (RobotStatus)       │ │
│  │   手柄按键值 → 拓扑排序求值 → 执行器指令         │ │
│  └─────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────┘
```

### 7.2 Pin 系统

```cpp
enum class PinType { Float, Bool, Int };  // 三种引脚类型，均可互联

struct EditorPin {
    ax::NodeEditor::PinId ID;
    EditorNode*           Node;
    std::string           Name;
    PinType               Type = PinType::Float;
};
```

- **Float**（绿色）：浮点值，默认类型
- **Bool**（橙色）：布尔值，内部用 ≥0.5 判定为 True
- **Int**（蓝色）：整数值，输出时自动取整
- 所有引脚类型**互相兼容**，跨类型连接自动转换（Float↔Bool↔Int）
- 每个引脚可通过 UI 上的小按钮循环切换类型

### 7.3 节点分类与通用结构

#### 五大分类

| 分类 | 枚举值 | 颜色 | 描述 |
|------|--------|------|------|
| **Math** | `NodeCategory::Math` | 橙色 | 数学运算 |
| **Shaping** | `NodeCategory::Shaping` | 紫色 | 信号塑形 |
| **Logic** | `NodeCategory::Logic` | 蓝色 | 逻辑与时序 |
| **Memory** | `NodeCategory::Memory` | 绿色 | 状态与记忆 |
| **Control** | `NodeCategory::Control` | 青绿 | 反馈与控制 |

#### EditorNode 通用字段

所有节点共享以下可序列化字段：

```cpp
struct EditorNode {
    NodeId  ID;              // 唯一标识
    string  Name;            // 显示名称
    NodeType Type;           // 节点类型枚举
    vector<EditorPin> Inputs;  // 输入引脚列表
    vector<EditorPin> Outputs; // 输出引脚列表

    float Value = 0;         // 主输出值（运行时更新）
    float InputValues[4];    // 输入引脚当前值（显示用）
    float Param[8] = {};     // 可配置参数（含义随节点类型变化）
    int   OpMode = 0;        // 操作模式选择器
    float StateF[4] = {};    // 内部浮点状态（记忆节点用）
    bool  StateB[4] = {};    // 内部布尔状态
    float StateDt = 0;       // 累计时间

    string KeyName;          // KeySource: 绑定按键名
    string OutputTarget;     // CustomOutput: 执行器字段路径
    int    GlobalVarId = -1; // GlobalRead/Write: 绑定全局变量ID
    vector<string> ModeLabels; // LookupTable: 槽位值列表
};
```

#### 7.4.1 特殊节点（不属于五大分类菜单）

##### KeySource — 按键输入源
- **NodeType**: `KeySource` (44)
- **分类菜单**: 独立菜单项 "Key Source"
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Value | Float | 绑定按键的当前值（模拟量/数字量） |
- **特殊字段**: `KeyName` — 绑定的手柄按键名称（点击按钮从弹窗选择）
- **运算**: `return keyValues[node.KeyName]` 或 0
- **用途**: 将手柄按键映射为节点图的数据源。模拟按键返回浮点值，数字按键返回 0/1
- **UI**: 点击按钮弹出按键选择列表；右键清空绑定

##### ConstValue — 常量值
- **NodeType**: `ConstValue` (45)
- **分类菜单**: 独立菜单项 "Const Value"
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Value | Float | 常量输出值 |
- **特殊字段**: `Value` — 可通过 DragFloat 拖拽修改（范围 -100~100，精度 0.01）
- **运算**: `return node.Value`
- **用途**: 提供固定的常数值作为其他节点的输入

##### CustomOutput — 输出节点
- **NodeType**: `CustomOutput` (46)
- **分类菜单**: 独立菜单项 "Output"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Value | Float | 要输出的值 |
- **特殊字段**: `OutputTarget` — 执行器字段路径（如 `"brushlessmotor.0.target_speed"`）
- **运算**: 直通输入值，并将结果写入 `OutputTarget` 对应的执行器字段
- **用途**: 将节点图计算结果映射到实际硬件执行器
- **UI**: 点击按钮弹出输出目标列表；右键清空绑定

##### GlobalRead — 全局变量读取
- **NodeType**: `GlobalRead` (38)
- **分类**: Memory
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Value | Float | 全局变量的当前值 |
- **特殊字段**: `GlobalVarId` — 绑定的全局变量 ID
- **运算**: 按 ID 查找全局变量并返回其值
- **用途**: 在多个节点图（不同模式）之间共享数据

##### GlobalWrite — 全局变量写入
- **NodeType**: `GlobalWrite` (39)
- **分类**: Memory
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Value | Float | 要写入的值 |
  | Trig | Float | 上升沿触发写入 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 全局变量的当前值 |
- **特殊字段**: `GlobalVarId` — 绑定的全局变量 ID
- **运算**: Trig 引脚上升沿时将 Value 写入全局变量
- **用途**: 跨模式数据共享（常配合 GlobalRead 使用）

##### ShortcutTrigger — 快捷键触发器
- **NodeType**: `ShortcutTrigger` (40)
- **分类**: Logic
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Trig | Float | 触发信号（上升沿触发） |
- **特殊字段**:
  - `ShortcutActionIndex` — 绑定的快捷键动作索引（面板切换）
  - `ShortcutSendIndex` — 绑定的发送帧索引（数据发送）
  - `ShortcutSendMode` — 发送模式（0=Toggle, 1=OneShot）
- **运算**: 直通输入值，上升沿（<0.5→>=0.5）时执行绑定的快捷键动作或数据发送
- **用途**: 将手柄按键映射到快捷键动作（如切换面板、发送命令帧）。双击节点选择绑定目标
- **执行路径**: 
  - **编辑器 Play** → `EvaluateForDisplay()` 在编辑器内预览触发
  - **RobotStatus 后台** → `EvaluateIntoActuators()` / `EvaluateCompute()` 自动响应手柄输入

#### 7.4.2 Math（数学运算）

##### Arithmetic — 四则运算
- **NodeType**: `AddSubMulDiv` (0)
- **标题**: "Arithmetic"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | A | Float | 操作数 A |
  | B | Float | 操作数 B |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 运算结果 |
- **OpMode** (4 种模式):
  | 0 | Add | A + B |
  | 1 | Sub | A - B |
  | 2 | Mul | A × B |
  | 3 | Div | A ÷ B (B=0 时返回 0) |
- **用途**: 基础四则运算，通过 ← → 按钮切换运算类型

##### Scale & Bias — 缩放偏移
- **NodeType**: `ScaleBias` (1)
- **标题**: "Scale & Bias"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入值 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 变换结果 |
- **参数**:
  | Param[0] | Scale | 缩放因子（默认 1.0） |
  | Param[1] | Bias | 偏移量（默认 0.0） |
- **公式**: `Out = In × Scale + Bias`
- **用途**: 线性变换，常用于手柄值映射到目标范围

##### Lerp — 线性插值
- **NodeType**: `Lerp` (2)
- **标题**: "Lerp"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | A | Float | 起始值 |
  | B | Float | 结束值 |
  | T | Float | 插值因子（自动钳制到 [0,1]） |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 插值结果 |
- **公式**: `Out = A + (B - A) × clamp(T, 0, 1)`
- **用途**: 在两值之间平滑过渡

##### Clamp — 钳制
- **NodeType**: `Clamp` (3)
- **标题**: "Clamp"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Value | Float | 输入值 |
  | Min | Float | 下限 |
  | Max | Float | 上限 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 钳制结果 |
- **公式**: `Out = clamp(Value, min(Min,Max), max(Min,Max))`
- **用途**: 限制值的范围

##### Remap — 区间映射
- **NodeType**: `Remap` (4)
- **标题**: "Remap"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Value | Float | 输入值 |
  | InMin | Float | 输入下限 |
  | InMax | Float | 输入上限 |
  | OutMin | Float | 输出下限 |
  | OutMax | Float | 输出上限 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 映射结果 |
- **公式**: `t = (Value - InMin) / (InMax - InMin)` → `Out = OutMin + t × (OutMax - OutMin)`
- **用途**: 将一个范围的值线性映射到另一个范围（如摇杆 [-1,1] → 电机 [0,100]）

##### Compare — 比较运算
- **NodeType**: `Compare` (5)
- **标题**: "Compare"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | A | Float | 操作数 A |
  | B | Float | 操作数 B |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Bool | Bool | 比较结果 (1.0/0.0) |
- **OpMode** (6 种模式):
  | 0 | A > B |
  | 1 | A >= B |
  | 2 | A <= B |
  | 3 | A < B |
  | 4 | A == B |
  | 5 | A != B |
- **用途**: 数值比较，输出布尔型结果

##### In Range — 区间判断
- **NodeType**: `InRange` (6)
- **标题**: "In Range"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Value | Float | 待判断值 |
  | Min | Float | 下限 |
  | Max | Float | 上限 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Bool | Bool | Value ∈ [Min, Max] |
- **公式**: `Out = Value ≥ Min AND Value ≤ Max`
- **用途**: 判断值是否在指定区间内

##### Select — 条件选择
- **NodeType**: `Select` (7)
- **标题**: "Select"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Cond | Float | 条件 (≥0.5 为 True) |
  | A | Float | True 时的输出 |
  | B | Float | False 时的输出 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | Cond ? A : B |
- **公式**: `Out = Cond ≥ 0.5 ? A : B`
- **用途**: 根据条件在两个值之间切换

##### Math Func — 数学函数
- **NodeType**: `MathFunc` (9)
- **标题**: "Math Func"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | A | Float | 第一参数 |
  | B | Float | 第二参数（仅 Atan2 使用） |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 函数结果 |
- **OpMode** (3 种模式):
  | 0 | Sin | sin(A) |
  | 1 | Cos | cos(A) |
  | 2 | Atan2 | atan2(A, B) |
- **用途**: 三角函数计算

#### 7.4.3 Shaping（信号塑形）

##### Dead Zone — 死区
- **NodeType**: `DeadZone` (12)
- **标题**: "Dead Zone"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 处理后的信号 |
- **参数**:
  | Param[0] | Dead Zone | 死区半宽（默认 0.1，范围 [0,1)） |
- **公式**: `|In| < dz → 0`；否则 `Out = sign(In) × (|In| - dz) / (1 - dz)`
- **用途**: 消除摇杆中立位置的噪声抖动，同时对有效范围重映射到 [0,1]

##### Curve — 曲线映射
- **NodeType**: `Curve` (13)
- **标题**: "Curve"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 映射后的信号 |
- **参数**: `Param[0..7]` = 4 个控制点 (x₀,y₀, x₁,y₁, x₂,y₂, x₃,y₃)，分段线性插值
  - 未设置的点（(0,0)且 i>0）自动跳过
  - 控制点按 X 排序
  - 超出范围时钳制到首尾点
- **用途**: 自定义非线性映射曲线（如油门响应曲线）

##### Quantizer — 量化器
- **NodeType**: `Quantizer` (14)
- **标题**: "Quantizer"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 量化后的信号 |
- **参数**:
  | Param[0] | Step | 量化步长（默认 1.0） |
- **公式**: `Out = round(In / Step) × Step`
- **用途**: 将连续信号离散化为阶梯值（如档位切换）

##### Hysteresis — 滞回比较器
- **NodeType**: `Hysteresis` (15)
- **标题**: "Hysteresis"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Bool | 滞回输出 |
- **参数**:
  | Param[0] | Threshold | 阈值（默认 0.5） |
  | Param[1] | Hysteresis | 滞回宽度（默认 0.1） |
- **行为**: `In > thr + hys → True`；`In < thr - hys → False`；中间保持
- **用途**: 防止信号在阈值附近来回跳变（有状态记忆）

#### 7.4.4 Logic（逻辑与时序）

##### Logic Op — 逻辑运算
- **NodeType**: `LogicOp` (16)
- **标题**: "Logic Op"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | A | Float | 操作数 A (≥0.5=True) |
  | B | Float | 操作数 B（NOT 模式忽略） |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Bool | 逻辑结果 |
- **OpMode** (4 种模式):
  | 0 | AND | A && B |
  | 1 | OR | A \|\| B |
  | 2 | XOR | A != B |
  | 3 | NOT | !A |
- **用途**: 组合多个布尔条件

##### Edge Detect — 边沿检测
- **NodeType**: `RisingEdge` (20)
- **标题**: "Edge Detect"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 待检测信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Bool | 边沿脉冲（单帧 True） |
- **OpMode** (2 种模式):
  | 0 | Rising | 上升沿检测：prev=0, cur=1 时输出 1 |
  | 1 | Falling | 下降沿检测：prev=1, cur=0 时输出 1 |
- **有状态**: StateB[0] 存储前一帧值
- **用途**: 检测按键按下瞬间、阈值跨越瞬间

##### Toggle — 翻转锁存
- **NodeType**: `Toggle` (22)
- **标题**: "Toggle"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Clk | Float | 时钟输入 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Q | Bool | 当前状态 |
- **行为**: Clock 上升沿时翻转输出（Q = !Q）
- **有状态**: StateB[0] 存储 Q，StateB[1] 存储前一帧 Clock
- **用途**: 一键开关、交替切换

##### SR Latch — SR 锁存器
- **NodeType**: `SRLatch` (23)
- **标题**: "SR Latch"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | S | Float | 置位（Set） |
  | R | Float | 复位（Reset） |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Q | Bool | 锁存输出 |
- **行为**:
  - S 上升沿 → Q = 1
  - R 上升沿 → Q = 0
  - 同帧 S/R 同时触发时 S 优先
- **用途**: 启动/停止逻辑、模式保持

##### Delay — 接通延时
- **NodeType**: `DelayOn` (25)
- **标题**: "Delay"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Bool | 延时输出 |
- **参数**:
  | Param[0] | Delay (s) | 延时秒数（默认 0.5） |
- **行为**: In=True 后等待 delay 秒 → Out=True；In=False 时 Out 立即 False
- **有状态**: StateDt 累计计时
- **用途**: 按键长按触发、防抖

##### Delay Off — 关断延时
- **NodeType**: `DelayOff` (26)
- **标题**: "Delay Off"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Bool | 延时输出 |
- **参数**:
  | Param[0] | Delay (s) | 延时秒数（默认 0.5） |
- **行为**: In=True → Out 立即 True；In 变 False 后保持 Out=True 持续 delay 秒
- **用途**: 动作完成后延迟关闭（如冷却延时）

##### Timer — 可重触发单稳态
- **NodeType**: `Timer` (27)
- **标题**: "Timer"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Trig | Float | 触发信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Bool | 定时器输出 |
- **参数**:
  | Param[0] | Duration (s) | 脉冲宽度（默认 0.5） |
- **行为**: Trig 上升沿 → Out=True 并持续 Duration 秒后自动 False
- **有状态**: StateB[0] 输出状态，StateDt 计时
- **用途**: 触发后持续一段时间的动作

##### Pulse — 边沿脉冲
- **NodeType**: `Pulse` (28)
- **标题**: "Pulse"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Bool | 脉冲输出 |
- **参数**:
  | Param[0] | Width (s) | 脉冲宽度（默认 0.1） |
- **行为**: 输入信号的任何边沿变化 → 输出固定宽度的脉冲
- **用途**: 将任意状态变化转化为标准宽度脉冲

#### 7.4.5 Memory（状态与记忆）

##### Unit Delay — 单位延迟 (z⁻¹)
- **NodeType**: `UnitDelay` (29)
- **标题**: "Unit Delay"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入值 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 上一帧的输入值 |
- **公式**: `Out = prev_In`；然后 `prev_In = In`
- **有状态**: StateF[0] 存储前一帧输入
- **用途**: 信号延迟一帧、构建差分

##### Sample & Hold — 采样保持
- **NodeType**: `SampleHold` (30)
- **标题**: "Sample Hold"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Value | Float | 待采样值 |
  | Trig | Float | 采样触发（上升沿） |
  | Reset | Float | 复位（解除锁定） |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 保持值 |
- **参数**:
  | Param[0] | Auto | 0=手动(Trig触发)，非0=自动(输入变化即采样) |
  | Param[1] | Latch | 0=跟踪模式，非0=锁定模式(首次采样后锁存) |
- **行为**: 手动模式 → Trig 上升沿采样；自动模式 → 输入变化即更新
- **用途**: 捕获峰值、锁定关键值

##### Accumulator — 累加器
- **NodeType**: `Accumulator` (31)
- **标题**: "Accumulator"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 累加值 |
  | Reset | Float | 复位（≥0.5 清零） |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Sum | Float | 累计和 |
- **公式**: Reset → Sum=0；否则 Sum += In
- **有状态**: StateF[0] 存储累加值
- **用途**: 持续累加计数

##### Integrator — 积分器
- **NodeType**: `Integrator` (32)
- **标题**: "Integrator"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 被积信号 |
  | Reset | Float | 复位（≥0.5 清零） |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 积分值 |
- **参数**:
  | Param[0] | Min | 积分下限（默认 0，与 Max 均为 0 时不限幅） |
  | Param[1] | Max | 积分上限 |
- **公式**: `Out += In × dt`；钳制到 [Min, Max]
- **用途**: PID 的 I 项、面积累计

##### Differentiator — 微分器
- **NodeType**: `Differentiator` (33)
- **标题**: "Differentiator"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | d/dt | Float | 变化率 |
- **公式**: `Out = (In - prev_In) / dt`
- **有状态**: StateF[1] 存储前一帧输入
- **用途**: 检测信号变化速率

##### Counter — 计数器
- **NodeType**: `Counter` (34)
- **标题**: "Counter"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Inc | Float | 递增触发（上升沿 +1） |
  | Reset | Float | 复位触发 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Count | Int | 当前计数值 |
- **参数**:
  | Param[0] | Reset Value | 复位目标值（默认 0） |
  | Param[1] | Cycle Limit | 循环上限（默认 5，≤0 时无上限） |
  | Param[2] | Start Value | 循环起始值（默认 0） |
- **行为**: Inc 上升沿 Count+1；超过 Limit 回绕到 Start Value；Reset 上升沿设为 Reset Value
- **用途**: 步骤计数、循环序列

##### Rate Limiter — 速率限制器
- **NodeType**: `RateLimiter` (35)
- **标题**: "Rate Limiter"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 目标值 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 平滑逼近值 |
- **参数**:
  | Param[0] | Up Rate | 上升速率限制（默认 10） |
  | Param[1] | Down Rate | 下降速率限制（默认 10） |
- **公式**: 每帧变化量 Δx 钳制到 `[-DownRate×dt, +UpRate×dt]`
- **用途**: 电机加减速平滑、防突变

##### Low Pass — 低通滤波器
- **NodeType**: `LowPass` (36)
- **标题**: "Low Pass"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 滤波后的信号 |
- **参数**:
  | Param[0] | Cutoff (Hz) | 截止频率（默认 10） |
- **公式**: `α = dt / (RC + dt)`；`Out = Out + α × (In - Out)` （一阶 IIR）
- **用途**: 去除高频噪声、平滑信号

##### Moving Average — 移动平均
- **NodeType**: `MovingAverage` (37)
- **标题**: "Moving Average"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | In | Float | 输入信号 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Avg | Float | 平均值 |
- **参数**:
  | Param[0] | Window | 窗口大小（默认 5） |
- **行为**: 初始阶段算术平均；窗口满后自动切换为指数移动平均
- **用途**: 信号平滑

#### 7.4.6 Control（反馈与控制）

##### PID — PID 控制器
- **NodeType**: `PID` (41)
- **标题**: "PID"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Setpoint | Float | 目标值 (SP) |
  | PV | Float | 过程变量 (PV) |
  | Reset | Float | 积分复位（≥0.5 清零积分和微分） |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Out | Float | 控制输出 |
- **参数**:
  | Param[0] | Kp | 比例系数（默认 1.0） |
  | Param[1] | Ki | 积分系数（默认 0） |
  | Param[2] | Kd | 微分系数（默认 0） |
  | Param[3] | Out Min | 输出下限（与 Out Max 均为 0 时不限幅） |
  | Param[4] | Out Max | 输出上限 |
- **公式**: `error = SP - PV`；`P = Kp×error`；`I += Ki×error×dt`；`D = Kd×(error - prev_error)/dt`
- **特性**: 积分抗饱和（输出钳制时回退积分项）
- **用途**: 闭环控制（如位置/速度/电流环）

##### Deadband Comparator — 死区比较器
- **NodeType**: `DeadbandComparator` (43)
- **标题**: "Deadband Comparator"
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Error | Float | 误差值 |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | OnTarget | Bool | 是否在死区内 |
- **参数**:
  | Param[0] | Band | 死区带宽（默认 0.01） |
- **公式**: `|error| ≤ band → True`
- **用途**: 判断系统是否到达目标位置

#### 7.4.7 Lookup Table — 查找表
- **NodeType**: `LookupTable` (47)
- **分类菜单**: Math 分类
- **输入引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Index | Int | 表索引（自动 floor 取整并钳制） |
- **输出引脚**:
  | 名称 | 类型 | 描述 |
  |------|------|------|
  | Value | Float | 对应槽位的值 |
- **特殊字段**: `ModeLabels` — 字符串列表，每个元素是一个可解析为 float 的数值
  - 默认 8 个槽位：`["0","1","2","3","4","5","6","7"]`
  - 可通过 +/- 按钮增减槽位
  - 可通过 ↑↓ 按钮调整顺序
- **公式**: `Value = parseFloat(ModeLabels[clamp(floor(Index), 0, N-1)])`
- **用途**: 用 Counter 选择预设值、模式切换映射

### 7.5 节点连接（EditorLink）

```cpp
struct EditorLink {
    ax::NodeEditor::LinkId ID;
    ax::NodeEditor::PinId  StartPinID;  // 输出端（源引脚）
    ax::NodeEditor::PinId  EndPinID;    // 输入端（目标引脚）
    ImColor Color = ImColor(255, 255, 255);
};
```

- 连接只能从 **Output Pin → Input Pin**
- 所有引脚类型互通（Float/Bool/Int 可互相连接）
- 输出值在求值时按输出引脚的类型自动转换（Bool→0/1, Int→round）

### 7.6 节点图求值流程

```
1. 构建拓扑排序 (TopoSortNodes)
   ├→ 分析所有 EditorLink 建立邻接表
   ├→ 计算每个节点的入度
   └→ BFS 队列排序，确定求值顺序

2. 准备全局变量
   └→ 将 GlobalVar[] 复制到临时 float 数组（按 id 索引，O(1) 查找）

3. 按拓扑序逐个求值 (ComputeNodeOutput)
   ├→ 从 pinVals map 读取每个 Input Pin 的当前值
   ├→ 调用节点特定的 compute 函数
   ├→ 输出按 Output Pin 类型转换（Bool/Int/Float）
   ├→ 将输出传播到下游连接的 Input Pin（写入 pinVals map）
   └→ CustomOutput 节点的值写入 outputs map

4. 输出映射
   ├→ 将 outputs map 中的值通过 WriteOutputToActuator 写入 ActuatorConfig
   └→ 字段路径如 "brushlessmotor.0.target_speed"

5. 回写全局变量
   └→ 将临时数组中被 GlobalWrite 修改的值写回 GlobalVar[]
```

**关键点**:
- 求值使用真实时间 dt（通过 `std::chrono::steady_clock` 计算帧间间隔）
- 带状态的节点（Memory/Logic/Control）在同一线程中持有 unique_lock 保证线程安全
- `EvaluateForDisplay` 额外更新 `InputValues[]` 和 `Value` 字段用于 UI 显示

### 7.7 全局变量系统（GlobalVar）

```cpp
struct GlobalVar {
    int      id      = 0;      // 唯一 ID（自动分配）
    std::string name;          // 变量名称（用户命名）
    float    value   = 0.0f;   // 当前值
    PinType  type    = PinType::Float;
    bool     visible = false;  // 是否在 RobotStatus 面板显示
};
```

- **作用**: 在同一个 NodeGraph 的不同模式子图之间共享数据
- GlobalRead 节点按 `GlobalVarId` 读取
- GlobalWrite 节点在 Trig 上升沿时将 Value 写入对应 ID 的全局变量
- 全局变量在 GraphMap 切换时保持（不随子图切换清空）
- 序列化到 YAML 的 `globals` 段

### 7.8 图模式映射（Graph Map）

```
RobotMode × GamepadMode → 独立子图
```

- 每个 `"RobotMode|GamepadMode"` 组合对应一个独立的节点图（序列化为 YAML）
- `SwitchGraph(robotMode, gamepadMode)` 切换活跃子图时：
  1. 保存当前图的全局变量
  2. 从 GraphMap 加载目标子图
  3. 恢复全局变量

### 7.9 YAML 序列化格式

- **GetGraphDataYaml()**: 纯数据（不含 ed:: 位置信息），用于 Clone/Runtime

### 7.10 AI 生成节点图指南

> 以下指南供 AI 助手理解如何为用户生成自定义节点图 YAML。

#### 基本原则
1. **数据流从 KeySource 开始，到 CustomOutput 结束**
2. **每个节点有唯一整数 ID**，由 `nextId` 函数分配（通常从 1 递增）
3. **连接 link 的 ID 也需要唯一**，建议使用较大数值避免冲突
4. **未连接的输入引脚默认值为 0**

#### 典型节点图模板

**示例 1: 简单摇杆→电机映射**
```
KeySource(AxisLX) → DeadZone → ScaleBias → CustomOutput(motor.target_speed)
```
- 手柄摇杆 X 轴 → 消除死区 → 缩放到目标范围 → 输出到电机

**示例 2: 按键控制开关**
```
KeySource(BtnA) → EdgeDetect(Rising) → Toggle → CustomOutput(led.state)
```
- 按钮 A 按下 → 上升沿检测 → 翻转锁存 → 控制 LED

**示例 3: PID 闭环控制（Counter 选择模式）**
```
KeySource(BtnUp) → Counter  → LookupTable → PID_Setpoint
KeySource(BtnDn) ↗                         ↗ PID → CustomOutput(motor.speed)
SensorFeedback ────────────────────────────┘
```

#### 生成 YAML 时的注意事项
- `type` 字段必须使用 NodeType 枚举数值（见每个节点的 NodeType 值）
- `param` 数组始终包含 8 个 float 值
- `state_f` 数组始终包含 4 个 float 值
- 有 OpMode 的节点需要设置 `op_mode`
- 引脚数量由 `input_types` 和 `output_types` 数组长度隐式定义
- PinType: 0=Float, 1=Bool, 2=Int

#### 常用组合模式
| 场景 | 节点链 |
|------|--------|
| 摇杆映射 | KeySource → DeadZone → ScaleBias → CustomOutput |
| 按键切换 | KeySource → EdgeDetect → Toggle → CustomOutput |
| 组合按键 | KeySource×2 → LogicOp(AND) → CustomOutput |
| 长按触发 | KeySource → DelayOn → CustomOutput |
| 限速控制 | KeySource → RateLimiter → ScaleBias → CustomOutput |
| PID 控制 | ConstValue(Setpoint) → PID ← Sensor → CustomOutput |
| 多档位 | KeySource×2 → Counter → LookupTable → CustomOutput |

### 7.12 如何新增一个节点类型

以新增 **"Abs"** 为例，六步完成：

1. `NodeLibrary.h` 枚举添加 `Abs = 48`
2. `NodeLibrary.cpp` — `GetNodePinDefs()` 注册引脚，`GetNodeTitle()` 注册标题
3. `NodeLibrary.cpp` — `ComputeNodeOutput()` 实现求值
4. `NodeLibrary.cpp` — `GetNodeCategory()` 注册到 Math 分类（右键菜单自动出现）
5. 无需修改序列化（NodeType 以整数自动序列化）
6. 重新编译即可

> `Param[0..7]`、`OpMode`、`StateF[0..3]` 等通用字段已内置。

### 7.14 编辑器图 vs 后台求值器

Robot-UI 中存在**两份** NodeGraph 实例：

| | 编辑器图 | 后台求值器 |
|---|---|---|
| **归属** | `NodeGraphManager::m_SelectedGraph` | `RobotStatus::m_GraphEvaluator` |
| **用途** | 可视化编辑 + Play 预览 | 生产求值，驱动执行器 |
| **同步** | ApplyEdit → `SyncFromManagerSelected()` | 首次 → `SyncActiveNodeGraph()` |
| **ShortcutTrigger** | Play 期间编辑器回调执行 | 后台 evaluator 回调执行 |

**同步原理**: 编辑器图 → `GetGraphYaml()` → YAML 字符串 → `LoadGraphData(yaml)` → 后台求值器
