## 8. 通信协议与硬件接口

### 8.1 HardwareInterface — 硬件通信实现

**文件**: `Robot-UI/src/Robot_API/hardware_interface.h`, `hardware_interface.cpp`

继承自 `RobotAPI` 接口：

```cpp
class HardwareInterface : public RobotAPI {
public:
    bool Initialize(const std::string& host_ip, int remote_port,
                    int local_port, int transport_type = 0) override;
    SensorData GetSensorData() override;
    void SendActuatorData(const ActuatorConfig& data) override;

    void SetProtocolConfig(const std::vector<ProtocolSendConfig>& configs) override;
    void SetProtocolReceiveConfig(const std::vector<ProtocolReceiveConfig>& configs) override;

private:
    SOCKET m_Socket;                 // UDP/TCP 共用 socket
    sockaddr_in m_RemoteAddr;        // 目标地址
    std::vector<ProtocolSendConfig>    m_ProtocolCfgs;
    std::vector<ProtocolReceiveConfig> m_ReceiveCfgs;

    std::vector<std::vector<uint8_t>> SerializeActuatorData(const ActuatorConfig& data);
    SensorData DeserializeSensorData(const std::vector<uint8_t>& raw_data);
};
```

### 8.2 协议帧结构

#### 发送帧

```
┌────────┬───────────┬──────────────────┬──────────┬────────┐
│ Header │ CMD_Byte  │  Payload  Fields  │ Checksum │  Tail  │
│ (N字节) │  (1字节)  │   (可变长度)      │ (可选)   │ (M字节) │
└────────┴───────────┴──────────────────┴──────────┴────────┘
```

- **Include Length**: 可选，在 Header 后自动插入 payload 长度字段
- **Big Endian**: 控制多字节字段的字节序
- **Checksum**: None / Sum8 / XOR8 / CRC16

#### 字段编码

每个字段可通过 `DataEncoding` 指定：
- **Float32/Float64**: IEEE 754 浮点数
- **Int8/16/32/64**: 有符号整数
- **Uint8/16/32/64**: 无符号整数
- **Bool**: 1字节布尔值

#### 字段路径映射

发送字段通过 `field_path` 映射到 `ActuatorConfig`：
```
brushlessmotor.0.target_speed   → 第0号电机的目标速度
brushlessmotor.1.target_speed   → 第1号电机的目标速度
servo.0.angle                   → 第0号舵机的角度
motion.x                        → 运动控制 X 轴
```

```cpp
struct RobotCommConfig {
    char name[64]        = "Default";
    char host_ip[64]     = "192.168.0.10";
    int  remote_port     = 8888;
    int  local_port      = 8888;
    int  transport_type  = 0;     // 0=UDP, 1=TCP, 2=Serial
```
