## 11. 文件格式规范

### 11.1 .rbt 文件格式 (Robot Config)

**扩展名**: `.rbt`  
**格式**: YAML  
**内容**: 机器人完整配置（模式、执行器、传感器、协议、手柄映射、节点图、视频流、通信）

```yaml
robot_ui_config:
  version: 1                              # 格式版本
  robot:
    selected_index: 0                     # 选中模式索引
    items:                                # 机器人模式列表
      - name: ROV                         # 模式名称
        gamepad_mapping: ""               # 关联手柄模式
        host_ip: ""                       # 目标 IP
        remote_port: 0
        local_port: 0
        protocol_type: 0                  # 0=UDP, 1=TCP, 2=Serial
        has_motion: true
        has_temperature: true
        has_humidity: false
        has_depth: true
        brushless_motors:                # 无刷电机列表
          - id: 0
            name: LeftFront
            target_speed: 0
            np_mid/pp_ini/...            # 推力曲线锚点
            pwm_min: 2600
            pwm_max: 3400
        servos: []                        # 舵机列表
        protocol_send:                   # 发送帧配置
          - name: "Send"
            command_byte: 0x00
            header: []
            tail: []
            checksum: 1                   # 0=None, 1=Sum8, 2=XOR8, 3=CRC16
            include_length: true
            big_endian: false
            fields:
              - name: "Motor 0 Speed"
                field_path: "brushlessmotor.0.target_speed"
                encoding: 0               # Float32
        protocol_receive:                # 接收帧配置
          - name: "Receive"
            command_byte: 0x01
            fields:
              - name: "Temperature"
                field_path: "temperature.value"
                encoding: 0
  gamepad:
    selected_index: 0
    items:
      - name: Default
        gamepad_type: 0                  # Xbox
        keys:
          - id: 0
            name: Forward
            is_analog: true
        mappings:
          - key_id: 0
            key_name: Forward
            gamepad_key: "1"             # GLFW 轴 ID
            is_analog: true
            is_bound: true
  node_graph:                            # 节点图项
    selected_index: 0
    items:
      - id: 0
        name: Default
        comm_index: 0
        editor_yaml: "..."               # 节点图 YAML
  live_stream:                           # 视频流配置
    items:
      - name: Camera1
        ip: "192.168.1.100"
        port: 554
        codec: 0                         # H264
        decoder: 0                       # SOFTWARE
  robot_comm:                            # 通信配置
    items:
      - name: Default
        host_ip: "192.168.0.10"
        remote_port: 8888
        local_port: 8888
        transport_type: 0                # UDP
        send_freq_hz: 100
  style:                                 # UI 样式
    theme: 0
    invert: false
    alpha: 1.0
  ui_state:                              # UI 状态 (保存但不一定加载)
    robot_status_open: true
    ...
```

### 11.2 .kernel 文件格式 (Kernel Config)

**扩展名**: `.kernel`  
**格式**: YAML  
**内容**: UI 状态 + 样式（不含机器人业务配置）

`.kernel` 文件与 `.rbt` 文件在**同一目录**，使用**相同主名**。

```yaml
robot_ui_config:
  version: 1
  style:
    theme: 0
    invert: false
    alpha: 1.0
  ui_state:
    about_open: false
    option_open: false
    robot_status_open: true
    node_editor_open: false
    terminal_open: false
    monitor_wall_open: false
    robot_active_mode: 0
    gamepad_active_mode: 0
    robot_path: "default.rbt"             # 相对路径
    robot_dirty: false
    recent_files:
      - "configs/my_robot.rbt"
```

### 11.3 路径便携化策略

为了实现跨电脑可移植（如从开发机拷贝到现场工控机），`FileManager` 实现了路径转换：

```
保存: 绝对路径 → 相对路径 (相对于 exe 目录)
     C:\Robot-UI\configs\rov.rbt → configs\rov.rbt

加载: 相对路径 → 绝对路径 (基于当前 exe 目录)
     configs\rov.rbt → C:\Robot-UI\configs\rov.rbt

注意：如果路径不在 exe 目录子树下，保持原样不转换
```

## 12. 扩展开发指南

### 12.1 添加新的节点类型

详见 [06-节点图系统 §7.12](06-节点图系统.md#712-如何新增一个节点类型)：
1. `NodeLibrary.h` 添加枚举
2. `NodeLibrary.cpp` 注册引脚/标题/计算/分类
3. 重新编译即可（YAML 序列化自动支持）
```

### 12.2 添加新的通信传输类型

1. 在 `HardwareInterface` 中扩展 `transport_type`：

```cpp
bool HardwareInterface::Initialize(..., int transport_type) {
    switch (transport_type) {
    case 0: /* UDP */ break;
    case 1: /* TCP */ break;
    case 2: /* Serial */ break;
    case 3: /* 新类型 */ break;
    }
}
```

2. 在 `RobotComm` UI 中添加选项。

### 12.3 添加新的传感器类型

1. 在 `robot_api.h` 中添加数据结构：

```cpp
struct PressureSensor { EncodedValue value; };
```

2. 修改 `SensorData` 和 `SensorConfig`：

```cpp
struct SensorData {
    // ... 现有 ...
    PressureSensor pressure;
};

struct SensorConfig {
    // ... 现有 ...
    bool has_pressure = false;
};
```

3. 在 `ConfigSerializer` 中添加序列化支持。
4. 在 `RobotStatus` 和 `RobotComm` UI 中添加显示/编辑。

### 12.4 添加新的 ImGui 主题

在 `imgui_style.h` 的 `ImGuiTheme` 枚举和 `imgui_style.cpp` 中添加：

```cpp
// imgui_style.h
enum class ImGuiTheme {
    // ... 现有 ...
    MyCustomTheme,
};

// imgui_style.cpp
ImGuiStyleManager& ImGuiStyleManager::MyCustomTheme() {
    ImGuiStyle& style = ImGui::GetStyle();
    // 设置颜色、圆角、间距等
    return *this;
}
```

### 12.5 关键技术注意事项

1. **线程安全**: `RobotStatus` 使用 `std::shared_mutex` 保护 `NodeGraph` 数据的并发访问（UI 线程 + 手柄线程）
2. **WinSock 冲突**: Windows 头文件中 `connect`/`bind`/`send`/`recv` 等宏需要 `#undef` 后使用
3. **Vulkan 资源**: `LiveStream` 的图像通过 `Walnut::Image` 封装，返回 Vulkan DescriptorSet 供 ImGui 渲染
4. **文件编码**: 项目使用 UTF-8 编码 (`/utf-8` 编译选项)
5. **GLFW 初始化**: 手柄线程需要独立的 GLFW 上下文或使用 `glfwGetJoystickAxes`（线程安全）
